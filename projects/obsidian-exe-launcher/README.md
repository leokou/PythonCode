# Obsidian EXE Launcher

Obsidian 插件，在左侧栏提供 ▶ 图标，点击弹出工具面板：

| 按钮 | 功能 |
|------|------|
| 📋 索引更新工具 | 更新所有目录索引 |
| 🔄 Home修改同步目录 | Home→目录同步 |
| 🔁 目录修改同步home | 目录→Home同步 |
| ✏️ 文件名标题检查 | 检查 .md 文件标题 |
| 📦 备份笔记 | 备份 Obsidian 笔记 |
| 🚀 同步GitHub | 同步两个仓库到 GitHub |
| 🐍 备份python代码 | 备份 Python 代码到 GitHub |

## 安装

1. 复制此目录到 `D:\Obsidian\LeoDiary\.obsidian\plugins\obsidian-exe-launcher`
2. 在 Obsidian 设置 → 第三方插件中启用

## 构建

```bash
npm install
npm run build
```

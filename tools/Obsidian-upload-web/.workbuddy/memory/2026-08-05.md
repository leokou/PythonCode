## 双bat双击"没反应"排障（重要坑）
- 现象：双击 `build-onedir.bat`/`build-exe.bat` 窗口一闪而过、不生成产物。
- 根因：Write 工具生成的 .bat 是 **LF 行尾**（CRLF=0）。Windows 批处理的 `^` 续行在 LF 下失效，第一条 `pyinstaller ... ^` 长命令被截断 → 语法错误 → 静默退出。
- 修复：用 python 把两个 .bat 的 `\n` 统一替换为 `\r\n`（CRLF）。修复后 `where pyinstaller` 命中 Python314 的 pyinstaller.exe，且 `python314 -c "import webview,PIL,pystray,requests,msal,keyboard"` 全部可导入 → 构建可达。
- 经验：**凡用 Write 生成 Windows .bat/cmd，必须转 CRLF**，否则 `^` 续行会静默失败。勿加 UTF-8 BOM（会让首行 `@echo off` 带 BOM 前缀而失效）。
- 输出位置确认：均落在 `D:\Python\tools\Obsidian-upload-web\dist\`（onedir→`dist\Obsidian-upload\` 文件夹；onefile→`dist\Obsidian-upload.exe`）。
- CLAUDE.md 约束 AI 不自动打包，故未实跑，由用户双击验证。

## UPX 5.2.0 压不了 .NET 程序集 → 二次 Build failed（重要）
- 现象：清缓存重跑后在 EXE 阶段又报 `bincache may be corrupted` + `SyntaxError: invalid syntax`，首行 `upx: ...\pythonnet\runtime\System.IO.Compression.ZipFile.dll: CantPackException: unexpected value in PE header`。
- 根因：UPX 5.2.0 无法压缩 .NET 托管程序集（pythonnet/runtime 下 140+ 个 `System.*.dll`/`Microsoft.*.dll`/`netstandard.dll`/`Python.Runtime.dll`）。失败写坏 bincache → 连锁报 corrupted。
- 关键反直觉点：**不能 `--exclude-module pythonnet`**。`webview/platforms/edgechromium.py` 运行时 `import clr`（pythonnet）并 `clr.AddReference('Microsoft.Web.WebView2.Core.dll')` 加载 WebView2——排除会让所有窗口黑屏。pywebview 把 pythonnet 列为 Required-by 即此理。
- 修复（已写入 build-onedir.bat / build-exe.bat）：保留 pythonnet，加 4 条 `--upx-exclude` 跳过 .NET 程序集：
  `System.*.dll` / `Microsoft.*.dll` / `netstandard.dll` / `Python.Runtime.dll`。原生 DLL（pywin32/Pillow 等）仍 UPX 压缩，保留体积收益。
- 验证：pythonnet/runtime 目录已枚举，上述 4 个 glob 覆盖其全部 DLL（System.*、Microsoft.Win32.Primitives、Python.Runtime、netstandard）。
- 注：本回合 corrupted bincache 已再次 `rm -rf "C:/Users/leokou/AppData/Local/pyinstaller/bincache01py31464bit"` 清掉，用户可直接重跑 build-onedir.bat。
